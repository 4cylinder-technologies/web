🧭 How ACE Works — Judging Criteria

(click to expand — the exact methodology behind every result)

1. Same question, every judge. Six judges — Claude, ChatGPT (GPT-4o), Microsoft Copilot, Perplexity, Grok, and Gemini — each receive the identical prompt with the identical tool catalog for every category:

You are an objective AI tool evaluator. For the category "<category>", which AI tool or app is objectively the best choice for a user prompt in this category?

Choose ONE from this list: <tool catalog>
Respond with exactly one line: TOOL_ID: one-sentence reason

2. Blind and independent. Judges are polled in parallel. No judge sees another judge's vote, no conversation history, no steering — one fresh prompt, one vote, one stated reason.

3. Majority rules. Most votes wins outright. Ties are re-tallied using only disinterested votes — a judge voting for its own model family (e.g. ChatGPT/Copilot for OpenAI-family tools) is discounted in the tie-break only, never in a clear majority. A still-tied result falls back to deterministic alphabetical order, so re-running the same votes can never flip a winner.

4. Human-approved. Every run is staged here for review. Nothing reaches the apps until it is explicitly approved and published.

5. Monthly, from scratch. Every category is re-judged each run with no memory of prior winners. Winners can and do flip — that's the point.
